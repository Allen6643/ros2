水下 ROV 单目视觉端到端控制与声呐建图导航

1. 概述与目标

本模块在同一套 MuJoCo 水下环境中实现两条完全由神经网络驱动的链路：

  1. 单目视觉端到端控制（对应任务④，5 分）： 前视相机图像 → CNN → [前进推力, 转向]，直接驱动 ROV 前进， 不经过任何显式的目标检测或位姿估计环节；
  2. 声呐建图与避障导航（对应任务③，5×3 分）： 8 向声呐测距扇 → 占据栅格地图（nav_msgs/OccupancyGrid）+ 神经网络判定开阔方向 → 避障转向修正。

1.1 核心目标

编号 目标 对应要求
① 单目图像 → 神经网路 → 控制指令（端到端） 任务(4)
② 声呐测距 → 射线投射 → 占据栅格建图 任务(3) 建图
③ 神经网络判定开阔方向 → 避障转向 任务(3) 导航
④ 一键 launch、入口以 main. 开头 注意 1、注意 2
⑤ 完整 gif 动图、公式推导与源码解析 报告要求

1.2 场景设定

  • 水下通道先直行（X 方向 0~7 m），再向右拐弯（沿 Y 方向延伸）， 用于验证建图与导航；
  • 通道内布置三种颜色（红/绿/蓝）的标记物，为视觉端到端网络提供可区分的视觉线索；
  • ROV 控制自由度保留前进、转向两维（端到端网络的直接输出维度）， 横滚/俯仰由姿态自稳抑制，深度由 PD 定深控制保持。

输出类别：0 = 左侧开阔，1 = 正前开阔，2 = 右侧开阔。

3.4 标签从哪来（关键设计）

视觉端到端标签：用"视觉伺服"规则充当专家 —— 以图像灰度水平亮度重心作为航向误差代理量：

标签确实是图像的可微函数，因此 CNN 能稳定拟合； 同时该伺服律本身是合理的控制律，学到的策略行为可解释。

声呐标签：由测距几何关系直接判定 —— 前向测距最大则记"正前开阔"，左侧平均测距最大则记"左侧开阔"，否则"右侧开阔"。

本项目实测踩到的两个 MJCF 陷阱

  1. <sensor> 不能写在 <body> 内部，必须是 <worldbody> 的兄弟节点， 否则报 Schema violation: unrecognized element；
  2. 加速度计的合法元素名是 <accelerometer>（不是 <accel>）； 纹理的 type 只能是 cube/skybox/2d，棋盘格须写 builtin="checker"。 这些错误只在 from_xml_path() 时暴露，光看代码发现不了。

5.2 射线投射建图（sonar_slam_node.py）

def _update_map(self):
    for d in HORIZONTAL_SONAR:          # 只投射水平方向
        r = self.ranges[d]
        if r >= 19.9:                   # 未命中物体，跳过
            continue
        ang = self.yaw + SONAR_BEARINGS[d]
        steps = int(r / self.res)
        for i in range(steps):          # 沿途标空闲
            wx = self.pos[0] + i * self.res * math.cos(ang)
            wy = self.pos[1] + i * self.res * math.sin(ang)
            cell = self._world_to_grid(wx, wy)
            if cell and self.grid[cell[1], cell[0]] == -1:
                self.grid[cell[1], cell[0]] = 0
        # 命中点标占据
        wx = self.pos[0] + r * math.cos(ang)
        wy = self.pos[1] + r * math.sin(ang)
        cell = self._world_to_grid(wx, wy)
        if cell:
            self.grid[cell[1], cell[0]] = 100

为什么区分 HORIZONTAL_SONAR 与 SONAR_FEATURE_ORDER

向下的测距（down）用于网络特征与定深，但不参与二维栅格投射 （它的方向在世界系 XY 平面上没有意义）。本项目第一次运行时正是因为 把 down 混进了投射循环而触发 KeyError， 现已用两个显式常量把两种用途分开。

5.3 训练/推理共享预处理（networks.py）

def preprocess_image(img, width=IMAGE_WIDTH, height=IMAGE_HEIGHT):
    """训练与推理共用，保证缩放方式、通道顺序、归一化完全一致。"""
    img = img.convert('RGB').resize((width, height))
    arr = np.asarray(img, dtype=np.float32) / 255.0
    arr = (arr - IMAGE_MEAN) / IMAGE_STD
    return np.ascontiguousarray(arr.transpose(2, 0, 1))   # HWC -> CHW

视觉端到端控制最容易出的隐性缺陷就是"训练与部署的图像预处理不一致"， 让两边调用同一个函数即可从结构上消除。

8. 常见问题排查

Q1: sonar_slam_node 启动后立即退出，日志有 KeyError

传入神经网络的声呐特征顺序（8 维，含 down）与参与二维射线投射的方向 （7 维，不含 down）必须区分开。本包用 SONAR_FEATURE_ORDER 与 HORIZONTAL_SONAR 两个常量显式分离，请勿混用。

Q2: 相机话题无数据 / 图像全黑

确认 export MUJOCO_GL=osmesa 且已安装 libosmesa6。

Q3: /rov/map 一直是空的（全是 −1）

说明声呐没有命中任何物体。可用 ros2 topic echo /rov/sonar/range_f 检查读数； 若读数恒为 20.0（量程上限），检查模型是否正确加载。

Q4: ROV 瞬间冲到通道尽头

force_scale 过大。本包默认 10 N（由标定实验确定），请勿随意放大。

Q5: 图片里的中文变成方框

系统缺少中文字体：sudo apt install fonts-noto-cjk。 本包绘图代码在找不到中文字体时会自动改用英文标签，不会画成方框。
