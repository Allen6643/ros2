手写 PPO 强化学习 ROV 轨迹跟踪与 PID 基线对比

包名：mjc_rov_ppo_tracking 仿真环境：MuJoCo 3.1.x + ROS 2 Humble（Ubuntu 20.04.6，Python 3.8.10） 神经网络：PPO（Actor-Critic），手写实现，CPU 训练

1. 概述与目标

本模块在 MuJoCo 中构建 2D ROV 平面运动环境，手写 PPO（Proximal Policy Optimization）算法训练 ROV 跟踪目标点，并与传统 PID 控制器做定量对比。与"键盘遥操"和"声呐分类"不同，这里关注的是强化学习控制策略的训练流程与性能评价。

核心任务： 1. 在 MuJoCo 环境中实现 ROV 平面运动（推力 + 水阻力阻尼）； 2. 手写 PPO：Actor（4→64→64→2）+ Critic（4→64→64→1）； 3. 先用 PID 做行为克隆预热，再 PPO 微调； 4. 离线对比 PPO 与 PID 的轨迹跟踪 MAE。

2. 算法原理

2.1 PPO 目标函数

L_CLIP(θ) = E_t[ min( r_t(θ)·Â_t, clip(r_t(θ), 1-ε, 1+ε)·Â_t ) ]

其中 r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t) 是新旧策略概率比，ε=0.2。

2.2 状态与动作

  • 状态 s = [x, y, vx, vy]（4 维）
  • 动作 a = [Fx, Fy]（2 维，限幅 ±5N）
  • 奖励 r = -sqrt((x-x*)² + (y-y*)²)（越接近目标奖励越大）

2.3 训练流程

  1. BC 预热（30 epoch）：用 PID 控制器采样，MSE loss 让 Actor 模仿 PID 输出
  2. PPO 微调（200 episode）：rollout 200 步，计算回报与优势，clip 更新
