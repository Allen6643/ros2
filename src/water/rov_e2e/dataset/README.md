# dataset — 端到端控制数据集

本目录由 `collect_data.py` 自动生成，用于存放**单目视觉 → [前进推力, 转向]** 的
行为克隆数据集。

## 目录结构

```
dataset/
├── images/
│   ├── 000000.png
│   ├── 000001.png
│   └── ...
└── labels.csv          # 表头：filename,forward,turn
```

`labels.csv` 示例：

```csv
filename,forward,turn
000000.png,1.000,0.000
000001.png,1.000,-1.000
000002.png,1.000,0.000
```

- `forward` ∈ [-1, 1]：前进推力归一化指令（对应 `/cmd_vel` 的 `linear.x`）
- `turn` ∈ [-1, 1]：转向归一化指令（对应 `/cmd_vel` 的 `angular.z`）
- 图像为 MuJoCo 模型 `forward_cam` 相机渲染的 RGB 画面，默认 160×120

## 为什么不在版本库里

图像数据集体积大（600 帧约几十 MB），且是**每台机器各自采集的实验产物**，
因此 `.gitignore` 已忽略本目录下的全部内容，只保留说明文件。

复现方式：运行 `train.py` 与 `collect_data.py` 即可在本地重新生成，
详见 `docs/water/rov_e2e.md`。

## 采集建议

- 帧数 300~600 即可满足课程作业（CPU 训练足够）；
- 采集时**变化动作**，不要长时间保持同一指令，否则网络会退化为常数输出；
- 让 ROV 在画面中经历左偏、居中、右偏三种状态，转向标签才有区分度；
- 静水环境（默认关闭洋流）条件下采集，与世界模型一致。
